======================================
【Pre-installation Instructions】

I. System Requirements
Before using this tool, please ensure that Python 3.13 is installed (you may use the version included with this package).

II. Dependency Online Installation
1. Press Win+R to open the "Run" dialog box;
2. Type "cmd" to open the Command Prompt window;
3. Enter the following commands sequentially in the command line:
python -m pip install pymem paddleocr opencv-python pyautogui pydirectinput keyboard
python -m pip install paddlepaddle-gpu==3.2.2 -i https://www.paddlepaddle.org.cn/packages/stable/cu129/

Imports for Windows :
py -3.12 -m pip install --upgrade pip
py -3.12 -m pip install paddlepaddle-gpu==3.2.2 -i https://www.paddlepaddle.org.cn/packages/stable/cu129/
py -3.12 -m pip install paddleocr==3.5.0 paddlex==3.5.1 opencv-python pillow numpy pyautogui pydirectinput pymem keyboard requests PyYAML typing-extensions
py -3.12 -c "import paddle, paddleocr, cv2, numpy, pyautogui, pydirectinput, pymem, keyboard;

Imports for Linux :
sudo dnf install -y python3.12 python3.12-pip python3-gobject python3-dbus gstreamer1-plugins-base gstreamer1
python3.12 -m pip install --upgrade pip
python3.12 -m pip install paddlepaddle==3.2.2 -i https://www.paddlepaddle.org.cn/packages/stable/cpu/
python3.12 -m pip install paddleocr==3.5.0 paddlex==3.5.1 opencv-python pillow numpy pyautogui mss pynput keyboard requests PyYAML typing-extensions dbus-python
